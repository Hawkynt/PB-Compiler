The persistent DRAW state, command dispatch and rotation decomposition in
DrawRuntime*.cs were informed by FreeBASIC's libgfx2 DRAW implementation:
https://github.com/freebasic/fbc/blob/5714d10adb21ba0d5d65d7d497ac32f509bb95ff/src/gfxlib2/gfx_draw.c
License source:
https://github.com/freebasic/fbc/blob/5714d10adb21ba0d5d65d7d497ac32f509bb95ff/src/gfxlib2/license.txt

The implementation is expressed as this compiler's typed IR, not vendored C.
QuickBASIC-specific scanning, WORD arithmetic, error handling, pixel aspect
and reference protocols are derived from genuine QuickBASIC 4.50 executions;
FreeBASIC's numeric rules and reference encoding are not compatible substitutes.
No Microsoft compiler or runtime code is included. Oracle fingerprints and
captured expected bytes are retained in the DRAW regression tests.
