# pb3.6 decompilation reference

_Generated by `scripts/gen-decompilation.sh` — do not edit by hand; edit the examples under
`docs/decompilation/` and regenerate._

Each pb3.6 language feature and optimizer pass is shown as a minimal program next to its
decompilation — `pbc --dialect pb36 --emit-basic`, which un-parses the bound program back to
PB 3.5-compatible source. This reveals exactly what each feature lowers to (the binder's
desugaring) and what the optimizer does on top of it. Constructs that lower below the source
level (a real branch for the ternary, a state machine for `YIELD`, a thunk for a closure) are
rendered in the nearest readable PB 3.5 form; their full machine lowering lives in the codegen.

> The optimizer column reflects the AST-level passes the back-emitter can see (dead-code
> elimination, `DEF SEG` coalescing). Tier-2/3 optimizations (constant folding, CSE, the
> peephole, the instruction scheduler, loop unrolling, inlining) operate below the source
> level and are documented in docs/PIPELINE.md and docs/PB36.md.

### YIELD generator

A FUNCTION containing YIELD becomes a generator consumed by FOR EACH.

<details><summary>pb36 source</summary>

```basic

  FOR i = 1 TO n
    YIELD i * i
  NEXT
END FUNCTION

FOR EACH v IN Squares(4)
  PRINT v
NEXT
```
</details>

> **Round-trips to PB 3.5:** ✅ the decompilation recompiles under `--dialect pb35` and runs with identical output.

**Decompiled (lowered to PB 3.5):**

```basic

TYPE Squares
  S_state AS INTEGER
  S_n AS INTEGER
  S_i AS SINGLE
  S_Current AS LONG
END TYPE
DIM S_foreach1 AS Squares
DIM v AS LONG
IF -1 THEN
  IF -1 THEN
    S_foreach1.S_state = 0
    S_foreach1.S_n = 4
  END IF
  DO WHILE Squares_MoveNext(S_foreach1)
    v = Squares_get_Current(S_foreach1)
    PRINT v
  LOOP
END IF

FUNCTION Squares_get_Current(THIS AS Squares) AS LONG
  Squares_get_Current = THIS.S_Current
END FUNCTION

FUNCTION Squares_MoveNext(THIS AS Squares) AS INTEGER
  SELECT CASE THIS.S_state
    CASE 0
      GOTO S_start
    CASE 1
      GOTO S_r1
    CASE ELSE
      GOTO S_done
  END SELECT
S_start:
  DIM i AS INTEGER
  THIS.S_i = 1
S_L1:
  IF THIS.S_i > THIS.S_n THEN
    GOTO S_L2
  END IF
  THIS.S_Current = THIS.S_i * THIS.S_i
  THIS.S_state = 1
  Squares_MoveNext = -1
  EXIT FUNCTION
S_r1:
  THIS.S_i = THIS.S_i + 1
  GOTO S_L1
S_L2:
S_done:
  THIS.S_state = -1
  Squares_MoveNext = 0
END FUNCTION

SUB Squares_Reset(THIS AS Squares)
  THIS.S_state = 0
END SUB
```

_With the optimizer: identical — this feature lowers entirely in the binder; the optimizer changes nothing at the source level._

### Nullable type

T? holds a value or NOTHING; ?? coalesces to a default when empty.

<details><summary>pb36 source</summary>

```basic
PRINT age ?? -1
```
</details>

## Optimizations

These are the optimizer passes whose effect is visible at the source level (the AST-level
passes the back-emitter can render). Compile with `--optimize` (the pb36 default) vs
`--no-optimize` to see the difference.

### Dead-code elimination (O2)

Statements after an unconditional GOTO (until the next label) are unreachable; the optimizer drops them.

<details><summary>pb36 source</summary>

```basic
DIM X AS INTEGER
X = 1
GOTO Finish
X = 999
PRINT "never runs"
Finish:
PRINT X
```
</details>

> **Round-trips to PB 3.5:** ✅ the decompilation recompiles under `--dialect pb35` and runs with identical output.

**Decompiled (lowered to PB 3.5):**

```basic
DIM X AS INTEGER
X = 1
GOTO Finish
X = 999
PRINT "never runs"
Finish:
PRINT X
```

**With the optimizer (`--optimize`, e.g. dead-code / `DEF SEG` cleanup):**

```basic
DIM X AS INTEGER
X = 1
GOTO Finish
Finish:
PRINT X
```

### DEF SEG coalescing (O10)

A DEF SEG with only segment-transparent statements before the next DEF SEG is redundant and dropped.

<details><summary>pb36 source</summary>

```basic
DIM X AS INTEGER
DEF SEG = &HB800
X = 5
DEF SEG = &HA000
POKE 0, 65
```
</details>

> **Round-trips to PB 3.5:** ✅ the decompilation recompiles under `--dialect pb35` and runs with identical output.

**Decompiled (lowered to PB 3.5):**

```basic

X = 5
DEF SEG = -24576%
```

**With the optimizer (`--optimize`, e.g. dead-code / `DEF SEG` cleanup):**


## Optimizations below the source level

The bulk of the optimizer rewrites the *generated machine code*, not the AST, so it does not surface
in a source decompilation. For completeness, these passes run during code generation (see
docs/PIPELINE.md for the tier model and docs/PB36.md for the per-pass detail):

| Pass | Tier | What it does |
|------|------|--------------|
| Constant folding | 2 (emit) | folds compile-time-constant arithmetic / comparisons |
| Sparse conditional constant propagation (SCCP) | 1 (IR) | propagates constants through branches, prunes dead arms |
| Copy propagation | 2 (emit) | replaces a copy's uses with its source, killing the copy |
| Common-subexpression elimination (local + cross-block) | 2 (emit) | reuses an already-computed value instead of recomputing |
| Global value numbering (GVN) | 1 (IR) | unifies provably-equal computations |
| Dead-store elimination (DSE) | 1 (IR) | drops stores whose value is never read |
| Loop-invariant code motion (LICM) | 1 (IR) | hoists invariant work out of a loop |
| Induction-variable simplification | 2 (emit) | strength-reduces `i*const` loop addressing |
| Strength reduction | 2 (emit) | rewrites `x*const` as shift+add, `x\const` as a reciprocal/shift |
| Loop unrolling | 2 (emit) | unrolls small constant-trip loops |
| Inlining | 2 (emit) | inlines small/leaf procedures |
| Tail-call optimization | 2 (emit) | reuses the frame for a tail self-call (constant stack) |
| Dense `SELECT CASE` -> jump table | 2 (emit) | replaces the compare chain with an indexed indirect jump |
| Instruction scheduler | post-emit | reorders the final byte stream to group loads / ALU work (latency hiding) |
| Peephole | post-emit | local instruction-pattern rewrites (accumulator short forms, sign-extended imm8, ...) |
| Register-parameter passing | 1 (pre) | passes leaf-call arguments in registers |
| Float demotion | 1 (pre) | demotes a DOUBLE to SINGLE when the program never needs the precision |
| Reachability tree-shaking (O22) | 3 (layout) | drops unreachable procedures, runtime helpers and unread DATA |
| Runtime trim / virtual BSS / `.COM` | 3 (layout) | shrinks the image: unused runtime, zero-init data behind the image, tiny-model `.COM` |
